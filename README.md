# 📂 Tasks Completed

## 🔹 Task 1 – Protein Sequence Analysis

**Objective:**
To analyze a protein sequence obtained from a biological database and identify homologous sequences using BLAST.

### Work Performed

* Retrieved the human Hemoglobin Beta (HBB) protein sequence.
* Obtained the sequence from UniProt.
* Performed BLASTP analysis.
* Studied homologous sequences.
* Analyzed sequence identity, similarity, alignment score, and E-value.
* Documented the results with screenshots and interpretation.

📁 **Folder:** `Task-1-Sequence-Analysis/`

## 🔹 Task 2 – Multiple Sequence Alignment

**Objective:**
To perform Multiple Sequence Alignment of proteins belonging to the same protein family and identify conserved regions and motifs.

### Work Performed

* Selected five hemoglobin beta-chain protein sequences.
* Performed Multiple Sequence Alignment using Clustal Omega.
* Compared conserved and variable regions.
* Examined sequence similarity between different organisms.
* Analyzed the resulting sequence relationship/tree.

### Sequences Studied

* Human HBB – P68871
* Chimpanzee HBB – P68873
* Gorilla HBB – XP_018891709.1
* Mouse HBB1 – P02088
* Horse HBB – F6RDD3

📁 **Folder:** `Task-2-Multiple-Sequence-Alignment/`

---

## 🔹 Task 3 – Protein Structure Analysis

**Objective:**
To study the predicted three-dimensional structure of a protein using AlphaFold and visualize structural features using PyMOL.

### Protein Studied

**Human Lysozyme C (LYZ)**

* **UniProt ID:** P61626
* **Organism:** Homo sapiens
* **Sequence Length:** 148 amino acids

### Work Performed

* Retrieved the protein information from UniProt.
* Obtained the predicted structure from the AlphaFold Protein Structure Database.
* Visualized the structure using PyMOL.
* Examined alpha-helices and beta-sheets.
* Studied the active-site region.
* Visualized catalytic residues.
* Examined cysteine residues and disulfide bonds.
* Generated structural images using PyMOL.

📁 **Folder:** `Task-3-Protein-Structure/`
