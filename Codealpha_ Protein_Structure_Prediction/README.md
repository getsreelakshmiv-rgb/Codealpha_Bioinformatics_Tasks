# Task 3 – Protein Structure Prediction

## Objective

To obtain the amino-acid sequence of a selected protein from UniProt,
use an AlphaFold-predicted three-dimensional structure, visualize the
model using PyMOL, and describe its major structural features.

## Protein Information

- Protein: Lysozyme C
- Gene: LYZ
- Organism: Homo sapiens
- UniProt Accession: P61626
- Sequence Length: 148 amino acids

## Tools Used

- AlphaFold Protein Structure Database
- PyMOL

## Structural Features

The predicted structure shows a compact globular lysozyme fold
containing an alpha-helix-rich region and a smaller beta-sheet region.
The mature protein contains four disulfide bonds and an active-site
cleft.

The catalytic residues are Glu53 and Asp70 in full-length UniProt
numbering.
